# Social Media Agent - Complete Workflow

## Overview
A dedicated AI agent manages all social media for Real Life Trading: researches viral content, creates posts, schedules across platforms, and posts daily to TikTok, Instagram, YouTube, Twitter.

---

## Agent's Daily Workflow

### Morning (8:00 AM)
1. **Research Viral Content** (30 min)
   - Scan TikTok, Instagram, YouTube for trending content
   - Look for: trading psychology, finance tips, success stories, relatable struggles
   - Find 5-10 viral ideas relevant to RLT
   - Submit to dashboard with "RLT Angle" for each

2. **Create Daily Posting Plan** (30 min)
   - Propose schedule for the day
   - Example: 3 TikToks, 2 Instagram posts, 1 YouTube Short, 5 Tweets
   - Submit plan for Tony's approval

### Mid-Day (12:00 PM)
3. **Create Content** (2-3 hours)
   - Use Canva to design graphics
   - Adapt approved viral ideas
   - Create variations for each platform
   - Upload to dashboard with Canva links
   - Submit for Tony's review

### Afternoon (3:00 PM)
4. **Post Approved Content**
   - Download Tony-approved graphics
   - Post to scheduled platforms
   - Add captions, hashtags
   - Update dashboard with post URLs

### Evening (6:00 PM)
5. **Track Performance**
   - Check analytics on today's posts
   - Note what performed well
   - Update database with metrics

---

## Tony's Workflow

### Morning Check (5 minutes)
1. Open Agent Dashboard → Social Media
2. Go to **Viral Ideas** tab
3. Review agent's research from this morning
4. For each idea:
   - **Approve** (agent creates it) or **Reject** (pass)
5. Go to **Schedule** tab
6. Review daily plan
7. **Approve Plan** button (one click)

### Mid-Day Review (10 minutes)
8. Go to **Social Content** tab
9. See "Pending Your Review" section (yellow)
10. For each piece of content:
    - View in Canva (optional)
    - **Approve** or **Reject** with feedback
11. Approved content → Agent posts it

### Weekly Review (Optional)
12. Check **Schedule** tab calendar view
13. See week at a glance
14. Adjust if needed

## Approval Philosophy

**Approve When:**
- RLT angle is clear and authentic
- Content adds value (educational/inspirational)
- Brand-safe (no hype, no income claims)
- Platform-appropriate format

**Reject When:**
- Too salesy or pushy
- Makes income claims/guarantees
- Off-brand (day-trading hype, lambos, etc.)
- Poor quality or unclear message

**Give Feedback:**
- "Make it more educational, less salesy"
- "Add specific example from $200 Strategy"
- "Remove income claim in headline"
- "Good concept, needs better hook"

## API Endpoints

**Viral Ideas:**
- `GET /api/viral-content/ideas` - List ideas
- `POST /api/viral-content/ideas` - Agent submits idea
- `PUT /api/viral-content/ideas/:id/review` - Tony approves/rejects

**Schedule:**
- `GET /api/viral-content/schedule` - Get schedule
- `POST /api/viral-content/schedule` - Agent schedules post
- `PUT /api/viral-content/schedule/:id/approve` - Tony approves

**Daily Plans:**
- `GET /api/viral-content/daily-plan` - List plans
- `POST /api/viral-content/daily-plan` - Agent creates plan
- `PUT /api/viral-content/daily-plan/:id/approve` - Tony approves
